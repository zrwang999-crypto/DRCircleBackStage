# DRcircle Standalone App

This is a standalone mobile app prototype built with Vite, React, and TypeScript.

## Start

```bash
npm install
npm run dev
```

The local development port is `3020`.

## Build

```bash
npm run build
```

The production output is generated in `dist/`.

## Notes

- The app opens directly on the main home screen.
- The current product shell is English-only.
- Smart Ring and Reserved Space are intentionally empty placeholders until their direction is confirmed.
